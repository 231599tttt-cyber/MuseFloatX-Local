# MuseFloatX 本地版

基于 MuseFloatX 第 38 版悬浮球直接改的本地版，不重开发，不调任何服务器。

## 用法（和第 38 版一样，只是后端换了）

1. 安装 APK，打开 App，先看主界面模型状态；
2. 开悬浮窗权限（在 App 里点按钮跳转到系统设置里开）；
3. 点“下载模型”，首次下载 Qwen3.5-2B Q4_K_M，约 1.40GB，建议连 WiFi 下载，下载可续传，下载完会校验大小和 SHA256；
4. 点“启动悬浮球”，悬浮球启动时会加载本地模型（首次加载要等一会儿）；
5. 在 X 里复制一条帖子，再点悬浮球，面板先出来，再自动读一次剪贴板，读到就直接生成；
6. 面板显示当前帖子（带边框的框框里，最多显示 300 字预览，全文用于生成）和 AI 回复；
7. 风格就是按钮：自然 / 幽默 / 简短，点哪个就按哪个生成一次；生成中点另一个风格是先取消当前那一通、再换风格重来，不是叠加；生成中点已选中的风格直接忽略；
8. 点“复制”后你自己去 X 粘贴，**不自动发送**。

不需要无障碍，不截图，不 OCR，不后台持续监听剪贴板。没复制就点球，面板会提示先复制再点球。

## 模型（纠正后的正确版本）

- 模型：Qwen3.5-2B，本身就是后训练对话版本，**不是 Base 版**，也不要去找一个带 Instruct 后缀的版本来替换它；
- 来源：bartowski/Qwen_Qwen3.5-2B-GGUF，原模型 Qwen/Qwen3.5-2B；
- 文件：Qwen3.5-2B-Q4_K_M.gguf，Q4_K_M 量化，约 1.40GB；
- 下载地址（App 里就是这个）：https://huggingface.co/bartowski/Qwen_Qwen3.5-2B-GGUF/resolve/main/Qwen_Qwen3.5-2B-Q4_K_M.gguf
  - 注意：文件列表里显示的名字是不带 Qwen_ 前缀的，但 resolve 下载的实际文件名带 Qwen_ 前缀，直接用不带前缀的名字下载会 404（已实测），App 里下载用的是带前缀的 URL，落盘保存时用不带前缀的干净名字；
- SHA256（Hugging Face 文件页公布）：`57a1085840f497d764a7fc5d346922dbde961efb54cc792ea81d694fd846a1d8`，下载完 App 会校验，不一致就删文件重下；
- 模型**不打进 APK**，APK 本身只有几十 MB，模型是首次使用时在 App 里另外下载的，下载完断网也能生成。

## 思考模式（纠正后的正确做法）

- Qwen3.5-2B 官方默认就是非思考模式。主办法是让 llama-server 直接用模型自带的聊天模板，不要自己覆盖一个会触发思考的模板；
- 系统提示词沿用第 38 版短句，只加一句“只输出回复正文，不要思考过程”作为第二层保险；
- 代码里对 `<think>...</think>` 的过滤只是兜底（ApiClient.ThinkFilter，流式跨块也能丢掉），不是主办法。

## 加载策略（不要常驻占内存）

- 悬浮球启动时加载模型，关闭悬浮球时卸载；
- 10 分钟没有生成也自动卸载，释放内存；下次点球再重新加载；
- 用 mmap 加载，让系统可以在内存紧张时回收模型页；
- 模型加载后不每次生成都重新加载：同一次悬浮球使用期间，模型只加载一次，生成只是调本地服务。

## 性能 / 内存（第一版测试参数）

- 上下文：默认 **1024 tokens**，不是写死的 512。主界面可以改：6GB 手机如果卡，可以改成 512；改完下次加载生效；
- 线程：4 个；
- 首次加载：mmap 加载 1.4GB 模型，旗舰机约十几秒，6GB 机器放宽到 180 秒超时；
- 生成：流式出字，首字先出来，不用等全文；温度 0.7，简短 80 tokens、自然/幽默 180 tokens（和第 38 版一样）；
- 目标：第一次加载一次，之后每条回复几秒出完（真机实测为准，6GB 手机尤其要测）。

## 编译

GitHub Actions 工作流 `.github/workflows/build-local-apk.yml`：

1. 用 CMake + Android NDK r27c 编 llama-server（arm64-v8a，最新 llama.cpp master，支持 Qwen3.5 的 Gated DeltaNet）；
2. 把 llama-server 放进 `app/src/main/assets/llama-server`，APK 里带上；
3. 再用 Gradle 编 debug APK，产物在 Actions 的 `MuseFloatX-Local-debug-apk` 里。

首次使用时 App 会把 assets 里的 llama-server 复制到应用私有目录并 chmod +x 再启动，assets 里的文件不能直接执行，这一步是必须的。

本地 Gradle 编译以前走不通，不要回头折腾本地编，直接看 Actions 结果。

## 安全 / 边界

- 不读私信，不自动发送，不做账号池，不托管账号，不索要任何账号密码、Cookie、API 密钥；
- 本地版没有任何远程服务、没有服务器地址、没有密钥可填，生成只走 `http://127.0.0.1:8080` 回环，别的设备连不进来；
- 帖子文字只放内存，不写磁盘，不外发。
